WordCraft Teacher
=================

Это локальный сервер для преподавателя. Ученики открывают в браузере адрес
этого компьютера и работают в WordCraft; преподаватель видит подключения и
может выдать доступ, включить капчу или приостановить ввод.

Запуск
------
1. Распакуйте архив в любую папку. Папка web должна лежать рядом с
   wordcraft-teacher (wordcraft-teacher.exe в Windows).
2. Запустите wordcraft-teacher.
3. Откроется панель преподавателя в браузере. Если не открылась, скопируйте
   адрес из окна программы.
4. Ученикам покажите адрес вида http://192.168.1.10:8770.

Порты
-----
8770 — для учеников (доступен в локальной сети).
8771 — панель преподавателя (только этот компьютер).

Если Windows или межсетевой экран спрашивает разрешение, разрешите доступ
для частных сетей.

Параметры
---------
wordcraft-teacher --port 8770 --admin-port 8771 --web-dir web --no-open

--no-open не открывать браузер автоматически.
